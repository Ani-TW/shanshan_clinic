# 山山兒童治療所 🏔️
「孩子可以靠近的那一座山，也是一座陪他一起走的山」
一個專注於兒童心理諮商與治療的診所網站，提供專業的兒童心理健康服務。

## 服務項目
🎮 遊戲治療 - 透過遊戲幫助孩子表達內心想法
🤲 感覺統合 - 協助孩子發展感官協調能力
💙 情緒調節 - 教導孩子識別和管理情緒
👨‍👩‍👧‍👦 親職諮詢 - 提供父母教養指導與支持

## 網站連結
https://ani-tw.github.io/shanshan_clinic/

## 技術規格
-靜態網站
-託管於 GitHub Pages
-響應式設計，適配各種裝置

## 設計理念
網站以「山」為核心意象，象徵穩定、陪伴與成長的力量。設計簡潔溫馨，營造讓孩子和家長都感到安心的環境。
